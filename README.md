مشروع rategames
فكرة المشروع : موقع بسيط لتقييم ومراجعة للألعاب , يعرض الالعاب مع متوسط تقييمها المحسوب من المراجعات , ويقدر اي زائر للموقع يفتح اي لعبة يشوف كل المراجعات السابقه او يضيف مراجعته الخاصة او لعبة جديدة 
مبني بلغة php ,وقاعدة بيانات mysql وكل البيانات ديناميكية من قاعدة البيانات 

المتطلبات لتشغيل الموقغ :
1- تحميل xampp 
2-جهاز مع انترنت 
3- محرر اكواد (اختياري)

طريقة التشغيل :
1- تحميل ملفات المشروع كامله ويجب وضعها في مجلد داخل مجلد htdocs الموجود داخل xampp وعادة يكون علو القرص C
2- فتح xampp وتشغيل apache و Mysql  من xampp control panel بالضغط على Start حتى يصبح اللون اخضر 
3- استيراد قاعدة البيانات  من خلال الضغط على   admin بجانب Mysql ,وستفتح صفحة Myphp Admin , ومنها يمكن استيراد قاعدة البيانات 
4- استيراد القاعدة : بعد فتح Myphp Admin , من التبويبات العلوية نختار استيراد (import) والضغط علو choose file , واختيار قاعدة المشروع بامتداد .sql بعد ذلك النزول لأسفل الصفحة والضغط على انطلق (go) بعد الانتهاء ستظهر في القائمة الجانبية قاعدة باسم reviews_db وتحتوي جدولين games , reviews و تحتوي بيانات تجريبية

5- بعد تشغيل apache , Mysql , والتأكد من وضح ملفات المشروع داخل مجلد في داخل مجلد htdocs يمكن فتح الموقع من المتصفح عن طريق
http://localhost/اسم الصفحة الرئيسية / اسم مجلد المشروع
مثال لو كان اسم المجلد rategame 
http://localhost/trategame/index.php

((ملاحظة مهمه )) : يجب ترك apache , Mysql في وضع التشغيل اثناء تصفح الموقع وعدم اغلاق xampp control panel
